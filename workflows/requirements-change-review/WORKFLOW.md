# Requirements Change Review

1. Compare source versions or the supplied change description.
2. Run the Requirements Change Impact Analyzer.
3. Identify potentially affected artifacts where mappings exist.
4. Re-analyze impacted requirements and clarify new gaps.
5. Run the Coverage Gap Analyzer for regression and traceability gaps.
6. Update traceability and prepare the QA handoff.
7. Distinguish confirmed impacts from likely, possible, and unknown impacts.

Do not claim artifacts changed or tests ran without evidence.
